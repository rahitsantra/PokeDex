##  Pokédex Web App

A modern and interactive Pokédex web application that allows users to search and explore Pokémon in real time using a public Pokémon API. Users can quickly find any Pokémon by name or ID and view detailed information including stats, types, abilities, and images.

The application is built with a strong focus on performance and user experience. It features a clean, responsive UI, smooth interactions, and fast data fetching using asynchronous API calls. Additional functionality such as search suggestions, filtering, and proper error handling ensures a seamless experience even with invalid inputs.

###  Features

* Search Pokémon by name or ID
* View detailed stats, types, and abilities
* Fast and efficient API integration
* Responsive and user-friendly interface
* Error handling for invalid searches

###  Tech Stack

* Frontend: HTML, CSS, JavaScript
* API: Pokémon REST API

###  Purpose

This project demonstrates practical frontend development skills, including working with external APIs, handling asynchronous data, and building a clean, interactive UI. It serves as a solid foundation for more advanced features like favorites, comparisons, or team building.
